# Bot assets

Drop the welcome image here as **`welcome.png`** (or `welcome.jpg`).

The `/start` command sends it directly to Telegram (file upload — no hosting or
public URL needed). If no image is present, `/start` falls back to a plain text
greeting.

- Format: PNG or JPEG — name it `welcome.png` / `welcome.jpg`
- Recommended: horizontal (16:9), large on-screen text, under 10 MB
