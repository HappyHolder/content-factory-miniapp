# Bot assets

Drop the welcome image here as **`welcome.jpg`**.

The `/start` command sends `assets/welcome.jpg` directly to Telegram (file
upload — no hosting or public URL needed). If the file is absent, `/start`
falls back to a plain text greeting.

- Format: JPEG (name it exactly `welcome.jpg`)
- Recommended: horizontal (16:9), large on-screen text, under 10 MB
