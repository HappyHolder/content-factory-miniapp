# LOW / HIGH — план вилки моделей по подписке

Статус: согласовано (экономика + продукт), реализация по фазам.
Дата фиксации: 2026-06-21.

## Идея

Каждый платный тариф раздваивается на два варианта одной подписки:

- **LOW** — дешёвые модели. Это в точности текущее поведение приложения.
- **HIGH** — те же самые режимы генерации, но на сильных моделях («вау», в т.ч. изображения).

Вилка LOW/HIGH — это **переключатель силы моделей**, а не разный набор функций.
Все режимы доступны в обоих вариантах; меняется только движок под капотом.

Принцип безопасности: **всё аддитивно, LOW = сегодня.** Существующие подписки
по умолчанию = LOW. Если ничего не переключать — поведение как сейчас, нулевой
риск регрессии на живом проде (publium.ru).

## Матрица моделей

| Режим | LOW (слабее, дешевле) | HIGH (сильнее, «вау») |
|---|---|---|
| Текст постов | DeepSeek V4 Flash | Claude Sonnet 4.6 (+ кэш промпта) |
| Обложка — Satori-шаблон | одинаково (без модели, бесплатно) | одинаково |
| Обложка — AI-HTML под пост | дешёвая модель (DeepSeek) | Claude Sonnet 4.6 |
| Обложка — artistic картинка | Flux | GPT Image 1.5 (medium) |
| Ассистент (чат) | DeepSeek + Tavily | Claude Sonnet 4.6 + Tavily |

- Поиск в сети (Tavily) — **база для всех** в ассистенте (и LOW, и HIGH).
- Поиск в сети в генерации постов — **не делаем** (контент приносит пользователь).
- GPT Image качество — **medium** (~$0.05/картинка). Не gpt-image-1 (устаревает
  2026-10-23) — брать GPT Image 1.5 или 2.
- Opus не берём (для чата и копирайтинга избыточен); опция «максимум» на потом.

## Цены (финал)

Курс расчёта: 1⭐ ≈ $0.013 на руки; ~125⭐ ≈ 1 Gram (TON).

| Тариф | LOW | HIGH |
|---|---|---|
| Blogger (STARTER) | 650⭐ / 5💎 | **900⭐ / 7💎** |
| Business (CREATOR) | 1800⭐ / 15💎 | **2500⭐ / 20💎** |
| Agency (STUDIO_PRO) | 10000⭐ / 80💎 | **13000⭐ / 105💎** |

Наценка HIGH ~+30–40%. Проверено: покрывает доп. себестоимость (текст→Claude,
Flux→GPT, чат→Claude) с положительным запасом на всех тарифах. AI-расход HIGH
≈ 25–29% выручки; валовая маржа после AI и серверов ~60–65%.

## Лимиты

| Тариф | Базовых генераций/мес | Беспл. перегенераций/пост | Чат (новый потолок) |
|---|---|---|---|
| Blogger | 20 | 3 (LOW) / 1 (HIGH) | 100 сообщений/мес |
| Business | 60 | 3 / 1 | 300 сообщений/мес |
| Agency | **1000 LOW / 400 HIGH** (был ∞) | 3 / 1 | 1000 сообщений/мес |

Два обязательных потолка (сегодня оба безлимитны — главные дыры по марже):
1. **Базовые генерации Agency** (1000/400 вместо ∞).
2. **Сообщения в чате** (нового счётчика сейчас нет вообще).

## Платные перегенерации (HIGH)

1 бесплатна; дальше — пакетами (без окна оплаты на каждый тап, списывается из
«запаса»). На LOW перегенерации остаются бесплатными (дёшево).

| Пакет | Цена | Себестоимость |
|---|---|---|
| 10 переделок | 100⭐ / 0.8💎 | ~$0.50 |
| 50 переделок | 400⭐ / 3.2💎 | ~$2.5 |

## Реализация по фазам

### Фаза 1 — демо-UI (фронт, безопасно для прода) ← делаем сейчас
- Тумблер «Базовые / Премиум» сверху экрана тарифов (`src/screens/PlansScreen.tsx`).
- В режиме «Премиум»: карточки показывают HIGH-цены + строки «под капотом»
  (Claude / GPT Image / умный ассистент). Кнопка покупки HIGH — **«Скоро»**
  (платёжный путь НЕ трогаем, пока бэк не готов).
- Тексты: `src/i18n/ru.ts`, `src/i18n/en.ts`.
- HIGH-прайс для отображения: `src/lib/payments.ts` (только для UI).
- Риск для прода: нулевой (аддитивно, LOW = текущее поведение).

### Фаза 2 — бэкенд-роутинг моделей
- Новая колонка `Subscription.modelTier` (`LOW` | `HIGH`), default `LOW`.
  Миграция безболезненна: все существующие строки становятся LOW.
- `server/src/lib/payments.ts` `PLAN_PRICING`: добавить HIGH-варианты + платёжные
  пути (Stars-инвойс / TON-проверка) для HIGH.
- Маршрутизация по запросу вместо глобального `AI_PROVIDER`: генератор и чат
  читают `modelTier` → выбирают движок (DeepSeek/Flux/Claude/GPT Image).
- Интеграция Claude на текст (через Replicate — канал уже есть на обложках; либо
  прямой Anthropic API — тогда родной web search) и GPT Image 1.5 на обложки.
- **Кэш промпта** (обязательно): вынести дату и динамику из кэшируемого префикса
  системного промпта в `chat.ts` и в генераторе.
- При роутинге на Claude убрать `top_p` (оставить только `temperature`) — иначе 400.
- Фронт: тумблер делает HIGH покупаемым; бейджи моделей в карточке.

### Фаза 3 — лимиты и пакеты
- Счётчик сообщений чата + сброс по периоду (`subscriptionLimits.ts`, `chat.ts`).
- Потолок базовых генераций Agency (1000/400).
- Урезать перегенерации HIGH до 1 (`MAX_*_REGENS_PER_POST` → по варианту).
- Пакеты перегенераций: покупка (Stars/TON), «запас», серверная проверка перед
  платной перегенерацией. Per-post счётчики уже есть
  (`GeneratedPost.textRegensUsed` / `imageRegensUsed`).

### Сквозное обязательство (все фазы)
- **Не списывать** генерацию/реген/пакет за неудачный результат или заглушку.
