# База знаний Publium для поддержки

Версия базы: 1.0  
Актуальность: Publium v1.3 и изменения после релиза до 15.07.2026.

## Назначение

Этот комплект — пользовательская база знаний Publium. Его можно загрузить в раздел «Материалы проекта» внутри экрана «Стиль канала», а затем включить в Community Manager настройки «Использовать документы проекта» и «Отвечать на вопросы о продукте».

Документы объясняют доступный интерфейс, рабочие сценарии, ограничения и устранение ошибок. Они содержат только сведения, необходимые пользователю приложения.

5. [05-plans-and-payments.md](05-plans-and-payments.md) — тарифы, квоты, оплата и промокоды.

## Как загрузить в Community Manager

1. Откройте Publium внутри Telegram.
2. Выберите нужный канал в верхнем переключателе.
3. Откройте «Профиль» → на карточке нужного канала нажмите «Стиль канала» → откройте раздел «Материалы проекта».
4. Загрузите пять Markdown-файлов из этой папки по одному.
5. Откройте «Профиль» → на карточке нужного канала нажмите «Сообщество» → выберите вкладку «Community Manager».
6. В «Знания и поддержка» включите «Использовать документы проекта» и «Отвечать на вопросы о продукте».
7. Задайте текст эскалации, например: «Я не уверен в этом ответе. Уточню у команды Publium».
8. Нажмите «Применить». Простое «Сохранить» оставляет изменения черновиком.
9. В разделе «Симулятор» задайте 5–10 вопросов по функциям и проверьте найденные фрагменты.

Поддерживаются PDF, DOCX, Markdown и TXT до 15 МБ. На один канал можно загрузить до 20 документов; из каждого хранится до 200 000 символов извлечённого текста. Если текст большого файла усечён, разделите его на несколько тематических документов.

## Границы публичной базы знаний

Этот комплект описывает только функции, доступные обычному пользователю Publium. В нём намеренно нет административных экранов, внутренних маршрутов, API, переменных окружения, серверных путей, структуры базы данных, webhook, секретов и защитных механизмов. Community Manager не должен сообщать или предполагать такие сведения. На любой вопрос о внутреннем устройстве он использует настроенный текст эскалации.

## Правила ответа для AI-поддержки

- Сначала отвечать по этим документам и подтверждённым FAQ.
- Не придумывать и не склеивать названия кнопок, вкладок и маршрутов интерфейса. Маршрут можно повторять только дословно, если вся последовательность есть в одном фрагменте документа.
- Настройка, которая влияет на функцию, не обязательно является местом запуска этой функции. Например, стиль канала влияет на панораму, но панорама создаётся внутри блока «Галерея», а не в разделе обложек.
- Если точного маршрута в документах нет, честно сообщить, что его нельзя подтвердить, и передать вопрос человеку по настроенному тексту эскалации.
- Не выдавать roadmap и старые планы за работающие функции.
- Если функция помечена «soon» или недоступна на тарифе пользователя, говорить об этом прямо.
- Не придумывать цены, лимиты, статус оплаты, состояние конкретного поста или бота. Для персонального состояния предлагать открыть соответствующий экран.
- Для актуальных цен, новостей и внешних фактов использовать интернет-ресерч только по его настройкам. Ссылки и названия источников в публичный чат не выводить.
- Не запрашивать у пользователя пароли, токены, seed-фразы, приватные ключи или Telegram initData.
- Не обещать восстановить удалённый канал, пост, документ или сообщение, если интерфейс предупреждает о необратимом удалении.
- При неуверенности использовать настроенную эскалацию, а не правдоподобную догадку.
